이벤트 버블링(Event Bubbling)은 자바스크립트에서 이벤트가 발생했을 때, 그 이벤트가 발생한 요소(타깃 요소)에서 
시작해 상위의 부모 요소들을 거쳐 최상위 요소까지 전파되는 현상을 의미합니다.

주요 개념
이벤트 전파 단계: 이벤트가 발생하면 브라우저는 세 가지 단계로 전파합니다.

캡처링 단계: 최상위 요소에서 시작해 이벤트가 발생한 요소까지 내려가는 단계.
타깃 단계: 실제 이벤트가 발생한 요소에서 처리되는 단계.
버블링 단계: 타깃 요소에서 시작해 다시 상위 요소로 전파되는 단계.
이벤트 버블링은 바로 이 마지막 버블링 단계를 의미합니다.

예시: 만약 <div> 내부에 <button>이 있을 때, 버튼을 클릭하면 버튼에 걸린 클릭 이벤트와 더불어 
그 버튼을 감싸고 있는 <div>에도 동일한 클릭 이벤트가 실행될 수 있습니다. 이는 이벤트 버블링으로 인해 발생하는 현상입니다.
이번트리스너에 (e) 를쓴다.

documenet.querySelector('.black-bg').addEventListener('click',function(e){ 
        e만넣으면 가능한 함수들
        e.target // 유저가 실제로 누른것만 작동
        e.currentTarget // 이벤트리스너 달린곳 == this;
        e.preventDefault(); // 이벤트 기본동작을 막아줌(submit 이나 클릭처럼) 
        e.stopPropagation(); // 내상위요소로 이벤트 버블링을 막아줌
        return  })
